## Usage

``` r
data(petqc)

```

## Format

A data frame with 7798 rows and 13 variables:

- SOURCE:

- NACCID:

  Participant ID

- NACCADC:

  ADC at which subject was seen (100 -9999)

- SCAN_DATE:

- SCAN_TIME:

- RADIOTRACER:

- LONIUID:

- SCANNER_MODEL:

- PASS_FAIL:

- FAIL_REASON:

- FAIL_REASON_OTHER:

- FAIL_STATUS:

- FUNDING_SOURCE:
