# uds_fcsf

NACCADRC UDS dataset. CSF link. The data is sourced from the file(s)
investigator_fcsf_nacc73.csv.

## Usage

``` r
data(uds_fcsf)
```

## Format

A data frame with 3046 rows and 23 variables:

- NACCADC:

  ADC at which participant was seen (100 –9999)

- NACCID:

  Participant ID

- CSFABETA:

- CSFPTAU:

- CSFTTAU:

- CSFLPMO:

- CSFLPDY:

- CSFLPYR:

- CSFABMO:

- CSFABDY:

- CSFABYR:

- CSFABMD:

- CSFABMDX:

- CSFPTMO:

- CSFPTDY:

- CSFPTYR:

- CSFPTMD:

- CSFPTMDX:

- CSFTTMO:

- CSFTTDY:

- CSFTTYR:

- CSFTTMD:

- CSFTTMDX:
